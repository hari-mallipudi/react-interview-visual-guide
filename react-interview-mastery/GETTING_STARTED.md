## 📅 Recommended 6-Week Study Plan

### Week 1-2: Foundation + Hooks
**Goal:** Master the fundamentals

**Daily (1-2 hours):**
1. Read one concept from study guide (30 min)
2. Review corresponding diagram (15 min)
3. Practice explaining out loud (15 min)
4. Write code example (30 min)

**Topics:**
- Phase 1: JSX, Components, Props, State, Events, Lists, Forms
- Phase 2: useState, useEffect, useContext, useRef, useMemo, useCallback

**Deliverable:** Build a simple todo app using hooks

### Week 3: Patterns + Performance
**Goal:** Understand architecture and optimization

**Daily (1-2 hours):**
1. Study one pattern (45 min)
2. Compare with modern approach (30 min)
3. Build small example (45 min)

**Topics:**
- Phase 3: HOC, Render Props, Context, Composition
- Phase 4: React.memo, Code splitting, Virtualization

**Deliverable:** Refactor todo app with optimizations

### Week 4: State Management + Testing
**Goal:** Production-ready skills

**Daily (1-2 hours):**
1. Learn state management tool (1 hour)
2. Write tests for existing code (1 hour)

**Topics:**
- Phase 5: Context API, Redux Toolkit, React Query
- Testing: Jest, React Testing Library

**Deliverable:** Add Redux and tests to todo app

### Week 5: Advanced Topics
**Goal:** Modern React features

**Daily (1-2 hours):**
1. Study Next.js features (1 hour)
2. Build with TypeScript (1 hour)

**Topics:**
- TypeScript + React
- Next.js (SSR, SSG, App Router)
- Server Components
- React 18+ features

**Deliverable:** Convert todo app to Next.js with TypeScript

### Week 6: Interview Prep
**Goal:** Interview confidence

**Daily (2 hours):**
1. Answer 5 interview questions (30 min)
2. Practice explaining concepts (30 min)
3. Work on portfolio project (1 hour)

**Focus:**
- Review all phases
- Practice common questions
- Build impressive portfolio piece
- Mock interviews

**Deliverable:** Complete portfolio project + interview readiness
